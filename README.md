
# Payroll SaaS Platform – Week 1

## Objective
This repository represents the Week 1 foundation setup for a Payroll SaaS application.
The focus is on understanding the payroll domain, SaaS architecture, and creating a clean,
maintainable project structure with proper documentation and Git workflow.

## SaaS Model
This application follows a Software-as-a-Service (SaaS) model where payroll functionality
is hosted centrally and accessed by multiple organizations via the internet.

## Selected Tech Stack
- Frontend: React.js
- Backend: Node.js with Express.js
- Database: PostgreSQL
- Version Control: Git & GitHub

## Project Structure
project-root/
├── frontend/
├── backend/
└── database/

## Git Workflow
- main: Production-ready branch
- dev: Integration branch
- feature/<task>: Individual feature branches

## Commit Convention
- feat: New feature
- fix: Bug fix
- docs: Documentation updates
